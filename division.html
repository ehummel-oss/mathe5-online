➗ Merkwissen: Division

6372 : 27 = 236
6372 = Dividend · 27 = Divisor · 236 = Quotient

✏️ Schriftlich: Von links nach rechts schrittweise teilen. Jede Ziffer des Ergebnisses durch Multiplikation und Subtraktion überprüfen.

🚨 Äußerst wichtig: Durch 0 darf man niemals teilen! 0 : 5 = 0 ist dagegen erlaubt. 0 : 0 ist ebenfalls nicht definiert.

🦄 Merkspruch: „Wer durch null teilt, tötet Einhörner!“

Bei einer Division mit Rest gilt: Dividend = Divisor · Quotient + Rest (Rest kleiner als Divisor).
